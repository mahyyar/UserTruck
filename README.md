# 🚚 UserTruck — Advanced Renewal & User Management Bot  
A powerful, fast and fully automated Telegram bot designed to manage user panels, renewals, reminders, advanced statistics, pagination, and admin controls — all in one clean and optimized system.

![UserTruck Banner](https://dummyimage.com/1200x300/000/fff&text=UserTruck+Bot)

---

# ⭐ Features

### 🔧 Core Features
- Add / Edit / Delete users  
- Search by username, numeric ID, panel name, or renewal day  
- Auto-renew scheduler at custom intervals  
- Daily notifications for due, overdue, and next-day renewals  
- Admin management panel  
- Full FSM handling  
- Super-clean UX with Back buttons everywhere  

---

# 📊 Advanced Statistics
UserTruck offers a **pro-level statistics dashboard**:

- Total registered users  
- Today renewals  
- Tomorrow renewals  
- Overdue users  
- Extended users  
- Users expiring in next 5 days  
- Pagination for large lists  
- Smart context-based page navigation  

---

# 🗂 User History & Notes
Each user has:

- Editable notes  
- Auto-generated history logs  
- Merge-safe record updates

# ⚡ Installation

## 🔥 Option 1 — One-Command Auto Installer (Recommended)

Run this on your Linux server:

```bash
bash <(curl -s https://raw.githubusercontent.com/mahyyar/UserTruck/main/install.sh)
```

Installer automatically:

✔ Installs Docker + Compose  
✔ Configures `settings.py`  
✔ Creates DB folders  
✔ Builds & runs the bot  
✔ Handles updates & uninstalling
